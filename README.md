# Sahngmin Yoo — Personal Website

Jekyll/Minimal Mistakes personal website for Sahngmin Yoo, adapted from the
[Hah Min Lew CV template](https://github.com/hahminlew/hahminlew.github.io).

## Local build

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

## Deployment

The public site is configured for <https://sahngmin.github.io> and the
`sahngmin/sahngmin.github.io` repository. Pushing the publishing branch updates
the GitHub Pages site.

Update the static Google Scholar citation snapshot periodically.

The CV served by the site is `images/Sahngmin_Yoo_CV_v2.pdf`.

## Template attribution

Layout and theme structure are preserved from Hah Min Lew's public template,
which itself credits Joonhyung Park, Keunhong Park, and Minimal Mistakes.
